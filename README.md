# 🌌 Astray - Little Planet

미지의 행성에 불시착한 탐험대원이 되어 탈출선을 복구하고 행성에서 탈출하는 웹 기반 게임입니다.

## 🎮 게임 소개

**Astray**는 우주 탐험을 테마로 한 2D 평면 탐험 게임입니다. 플레이어는 산산조각 난 탈출선을 복구하기 위해 행성을 탐험하며 필요한 부품들을 수집해야 합니다.

### 🎯 게임 목표
- 행성 전체를 탐험하며 **10개의 탈출선 부품**을 수집
- 외계 언어 조각과 지도 조각 등 **단서들을 발견**
- 모든 부품을 수집한 후 **탈출선으로 이동하여 행성에서 탈출**

## 🕹️ 조작법

| 키 | 동작 |
|---|---|
| **W** | 위로 이동 |
| **A** | 왼쪽으로 이동 |
| **S** | 아래로 이동 |
| **D** | 오른쪽으로 이동 |
| **E** | 상호작용 (아이템 수집) |
| **I** | 인벤토리 열기/닫기 |

## 🌍 게임 요소

### 🟢 플레이어
- 초록색 사각형으로 표시
- 4방향으로 자유롭게 이동 가능
- 구조물에 부딪히면 자연스럽게 밀려남

### 🟡 탈출선 부품 (10개)
- 금색 사각형으로 표시
- 행성 전체에 흩어져 있음
- E 키로 수집 가능
- 수집한 부품은 인벤토리에 저장

### 🔵 단서
- 청록색 사각형으로 표시
- 외계 언어 조각과 지도 조각
- 게임 스토리와 힌트 제공

### 🏛️ 구조물
- **폐허**: 갈색 사각형 (장애물 역할)
- **동굴 입구**: 검은색 사각형
- **큰 폐허**: 더 큰 갈색 구조물

### 🚀 탈출선
- 우측 상단에 위치한 파란색 사각형
- 모든 부품을 수집한 후 접근 가능
- 게임 클리어 조건

## 📊 게임 상태

### 체력 시스템
- **체력**: 100에서 시작
- **산소**: 시간이 지날수록 감소 (0.05/프레임)
- 산소가 0이 되면 체력이 감소
- 체력이 0이 되면 게임 오버

### 인벤토리
- 수집한 아이템과 단서를 저장
- I 키로 열기/닫기 가능
- 아이템은 ⚙️, 단서는 📜 아이콘으로 표시

## 🎨 시각적 특징

- **우주 배경**: 별이 빛나는 우주와 행성 표면 그라데이션
- **미니맵**: 우측 상단에 위치한 작은 맵
- **디버깅 정보**: 좌측 상단에 게임 상태 표시
- **메시지 로그**: 하단에 게임 이벤트 표시

## 🚀 실행 방법

1. 모든 파일을 같은 폴더에 저장
2. `index.html` 파일을 웹 브라우저에서 열기
3. 게임 시작!

## 📁 파일 구조

```
├── index.html      # 메인 HTML 파일
├── style.css       # 게임 스타일시트
├── game.js         # 게임 로직 및 렌더링
└── README.md       # 이 파일
```

## 🎯 게임 팁

1. **산소 관리**: 산소가 부족해지기 전에 빠르게 탐험하세요
2. **체계적 탐험**: 맵을 체계적으로 탐험하여 모든 부품을 놓치지 마세요

## 🛠️ 기술 스택

- **HTML5 Canvas**: 2D 그래픽 렌더링
- **JavaScript**: 게임 로직 및 상호작용
- **CSS3**: UI 스타일링 및 레이아웃

## 📝 개발 정보

- **게임 엔진**: 순수 JavaScript (Canvas API)
- **물리 엔진**: 커스텀 충돌 감지 시스템
- **렌더링**: 60fps 애니메이션 루프
- **입력 처리**: 키보드 이벤트 리스너
